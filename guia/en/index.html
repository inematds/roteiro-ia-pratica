Overview

This artificial intelligence study and practice kit is for anyone who wants to understand the subject and make a first improvement at work. It brings together a video analysis, a glossary, and templates for assessing a process, writing a prompt and evaluating results. Start with a real task and check the outcome before automating it. To use the documents, simply read and copy them; the optional evaluation tool runs in Python without external services.

Your first pilot, step by step

You can take the first steps with a text editor and the assistant you already use.

1

Choose something small and repetitive

Example: organizing meeting notes. Record the input, output, time needed manually and who will review it.

Open the process assessment (in Portuguese)
2

Specify what a good answer needs to include

Provide context, source material, a format and criteria. Ask the assistant to flag missing information.

Copy the prompt template (in Portuguese)
3

Test different cases

Include typical cases, incomplete data and ambiguous requests. Evaluate failures too.

Download the evaluation spreadsheet (in Portuguese) · Review checklist (in Portuguese)
4

Compare the total effort

Add up time spent using the tool, reviewing and correcting. To calculate locally, clone the project and run the evaluation tool:

git clone https://github.com/inematds/roteiro-ia-pratica.git
cd roteiro-ia-pratica
python3 scripts/avaliar.py recursos/avaliacao.csv

The initial spreadsheet is empty: the program reports pending cases without making up a percentage improvement.

5

Decide based on what you observed

Adopt, adjust or abandon the pilot. Record your reasons before connecting systems.

An example that fits into your day

Fictional data for testing without relying on an integration.

Input

“At the meeting, we decided to revise the proposal. Ana took responsibility. We have not set a date yet.”

Expected output

Decision: revise the proposal. Owner: Ana. Deadline: not provided.

If the assistant invents a date, the output fails the factual accuracy criterion. This simple test shows why context and review need to go together.
