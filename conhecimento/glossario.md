# Glossário de trabalho

Explicações editoriais para usar os recursos desta base; não são citações literais.

| Termo | Explicação | Cuidado prático |
|---|---|---|
| Inteligência artificial | Campo de métodos computacionais usados em tarefas de percepção, previsão, linguagem e decisão | IA é mais ampla que chatbots |
| Aprendizado de máquina | Ajuste de modelos a partir de exemplos e objetivos de treinamento | Dados de treino não são garantia de resposta correta |
| Rede neural | Modelo composto por operações parametrizadas, ajustadas durante o treino | Analogia com cérebro não significa equivalência biológica |
| LLM | Modelo de linguagem de grande porte que produz e processa sequências de tokens | Fluência não prova precisão |
| Token | Unidade usada para representar texto; pode ser parte de palavra, palavra ou símbolo | Não equivale sempre a uma palavra |
| Transformer | Arquitetura que usa atenção para relacionar posições de uma sequência | Não descreve sozinho todo o produto de IA |
| Atenção | Operação que pondera informação de diferentes posições da entrada | Não significa consciência |
| Pré-treinamento | Etapa de aprendizagem em grande conjunto de dados antes de adaptações específicas | Não confundir com busca na web durante uma conversa |
| Inferência | Execução de um modelo já treinado para produzir uma resposta | Uma conversa comum não necessariamente altera seus pesos |
| Contexto | Informações disponíveis ao modelo naquela execução | Contexto disponível não significa uso perfeito de todo o material |
| Prompt | Pedido e instruções fornecidos ao sistema | Clareza ajuda, mas não garante verdade |
| Alucinação | Conteúdo gerado sem sustentação adequada, por vezes apresentado com confiança | Conferir fontes e números |
| Modelo | Componente que transforma entradas em saídas | É diferente do aplicativo que o utiliza |
| Aplicativo | Interface e funções construídas ao redor de um ou mais modelos | Pode incluir busca, arquivos, memória e integrações |
| Workflow | Fluxo de etapas definido para executar uma tarefa | Pode funcionar sem decisões autônomas de um modelo |
| Agente | Sistema no qual o modelo participa da escolha de ações e ferramentas para um objetivo | Exige limites, observação e avaliação |
| API | Interface pela qual programas trocam comandos e dados | Assinatura de aplicativo não implica acesso ou cobrança de API incluídos |
| GPU | Processador adequado a operações paralelas usadas em muitos cálculos de IA | Memória, energia e transferência de dados também importam |
| Avaliação | Comparação de saídas com critérios e casos definidos | Uma demonstração que deu certo não mede confiabilidade |
| Autoaperfeiçoamento recursivo | Ideia de sistemas ajudarem a melhorar sistemas que, por sua vez, aceleram novas melhorias | Hipótese e progresso parcial não equivalem a autonomia ilimitada comprovada |

Fontes de apoio: [Attention Is All You Need](https://arxiv.org/abs/1706.03762) e [Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents). As definições são sínteses educativas; os limites de uma implementação dependem do sistema concreto.
