# Checklist de saída

- [ ] A entrega responde ao pedido e segue o formato combinado.
- [ ] Cada fato tem apoio no material ou em fonte conferida.
- [ ] Informação ausente aparece como ausente.
- [ ] Inferências estão identificadas.
- [ ] Não houve envio não autorizado de dados ou mensagens.
- [ ] Números, unidades, nomes e datas foram conferidos.
- [ ] Tempo de revisão e correção foi registrado.
- [ ] Uma pessoa responsável aprovou o uso do resultado.
- [ ] Existe uma forma de retomar o processo manual.

Este checklist é um recurso autoral de aplicação; não é uma transcrição do vídeo.
